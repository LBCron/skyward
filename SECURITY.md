# Security

Please report a vulnerability privately, through [a GitHub security advisory](https://github.com/bottrall/skyward/security/advisories/new), rather than in a public issue. Say which gem and version it affects, and how to reproduce it.

You'll hear back within a week. Once a fix is released, the advisory is published with credit to you, unless you'd rather not be named.

## Supported versions

Skyward is pre-1.0, so security fixes go into the latest release only. All four gems release together at the same version, so upgrading means upgrading `skyward-core`, `skyward-api`, `skyward-orm` and `skyward` together.
